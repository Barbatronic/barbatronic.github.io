Application de suivi sportif (course, vélo, randonnée, trail, marche) qui garde les séances sur le téléphone : pas de compte à créer, pas de télémétrie, pas de serveur qui reçoit les données.

**Kairn Desk** est le complément sur ordinateur : il affiche les séances en grand (carte, allure par segment, dénivelé) en lisant le dossier où le téléphone les a écrites.

Projet jeune : pas encore de version sur le Play Store.
